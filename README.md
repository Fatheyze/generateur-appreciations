# Générateur d'appréciations

Outil pour rédiger les appréciations des bulletins de mathématiques à partir de l'export des notes de Pronote (CSV ou Excel).

- Import du fichier de notes de la classe, avec un chapitre par devoir
- Appréciation proposée pour chaque élève : résultats, évolution, chapitres réussis ou à retravailler
- Critères à ajouter au besoin : participation, travail en classe et à la maison, attitude et concentration
- Appréciation générale de la classe et préparation du conseil de classe

Toutes les données restent dans le navigateur : aucune note ni aucun nom d'élève n'est envoyé sur Internet.
